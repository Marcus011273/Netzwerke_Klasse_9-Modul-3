Warum brauchen Geräte Adressen?

Stell dir vor, du willst einer Freundin einen Brief schicken. Ohne Adresse wüsste die Post nicht, wohin damit. Ähnlich brauchen Geräte in Netzwerken Adressen.

Merkwissen: Eine IP-Adresse ist eine Netzwerkadresse, mit der ein Gerät beziehungsweise seine Verbindung im Netzwerk erreicht werden kann. In unserem Übungsnetz verwenden wir IPv4-Adressen wie 192.168.1.20. Das sind vier Zahlen von 0 bis 255, durch Punkte getrennt. Du musst heute keine Subnetze berechnen.

Station 5 · ca. 7 Minuten

Private und öffentliche IP-Adressen

Ein Gerät kann im Schulnetz eine private IP-Adresse haben. Beim Zugang zum Internet verwendet das Netzwerk nach außen oft eine öffentliche IP-Adresse.

📱Tablet192.168.1.20privat, im Schulnetz
🌐Routerverbindet Netze, oft NAT
🖥️Webserverim Internet
Eine private Adresse wie 192.168.1.20 wird nicht direkt über das öffentliche Internet weitergeleitet. Viele Heim- oder Schulnetze verwenden NAT (Netzwerkadressübersetzung): Der Router übersetzt Verbindungen nach außen. Eine öffentliche IP-Adresse kann mit mehreren Geräten geteilt werden. Sie identifiziert daher nicht automatisch eine einzelne Person.
